## 🛠️ Features & Concepts Used

- **Lists & Sets:** Used to store items and efficiently extract unique entries.
- **Loops & Collections (Counter):** Used to compute duplicate frequencies.
- **File Handling & Exception Handling:** Handles file reading, line parsing, missing file errors, empty file errors, and writing output.
- **Dual Matching Modes:**
  - **Option 1 (Exact Match):** Retains exact case and spaces.
  - **Option 2 (Ignore Case & Extra Spaces):** Normalizes case and removes trailing/leading spaces.
